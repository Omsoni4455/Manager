# Problem Statement & Scope

## Problem Statement
Tracking daily personal expenses and managing overall savings manually is prone to errors. This tool automates basic expense and income logging with CLI interface.

## Target Users
- Students managing personal allowances.
- Anyone looking for a simple text-based local spending tracker.

## Features
- Income and Expense CRUD logging.
- Financial analytics (total savings, balance, top expense).
- Text-file based data persistence.
